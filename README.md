# Cloud-Based Community Volunteer Management System

## 1. Project Overview

This project is a cloud-based web application designed to help community organizations manage volunteer registrations, contact information, availability, preferred roles, and status.

The application uses Firebase Realtime Database for cloud-based data storage and realtime synchronization.

## 2. Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap 5
- Firebase Realtime Database
- Firebase Authentication
- GitHub

## 3. Project Features

- Volunteer registration
- View registered volunteers
- Edit volunteer information
- Delete volunteer records
- Realtime data synchronization
- Input validation and error handling
- User authentication and database security
- Responsive user interface

## 4. Firebase Database Structure

The database stores volunteer records under the `volunteers` node.

Each volunteer record contains the following fields:

| Field         | Data Type | Description                      |
| ------------- | --------- | -------------------------------- |
| Volunteer ID  | String    | Unique key generated by Firebase |
| fullName      | String    | Volunteer full name              |
| email         | String    | Email address                    |
| phoneNumber   | String    | Contact number                   |
| availability  | String    | Weekdays, Weekends, or Both      |
| preferredRole | String    | Preferred volunteer role         |
| status        | String    | Active or Inactive               |

## 5. Firebase Files

| File                   | Description                                             |
| ---------------------- | ------------------------------------------------------- |
| js/firebase-config.js  | Firebase initialization and database configuration      |
| js/firebase-test.html  | Firebase authentication and database connection testing |
| js/sample-data.json    | Sample volunteer records                                |
| js/database.rules.json | Firebase Realtime Database security rules               |

## 6. Setup Instructions

1. Clone the GitHub repository.
2. Open the project folder in Visual Studio Code.
3. Install the Live Server extension if needed.
4. Open the application using Live Server.
5. Use the configured Firebase project.
6. Sign in with an authorized Firebase user account to access volunteer records.

Firebase is initialized in `js/firebase-config.js`.

The database security rules require authenticated users to access volunteer records.
